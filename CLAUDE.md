# Asset Forge factory workspace

A production space for building game assets (GLB models + optional pixel-art sprites) out of Kenney's Asset Forge block library. The user brings a work order, Claude builds the assets, and the user collects them from `Assets/`. Use the `asset-forge` skill (`.claude/skills/asset-forge/`) for every build. It holds the workflow, API, conventions and placement recipes.

## Layout

`GUIDE.md` is the user's plain-language manual. Keep it in sync when workflows change.

## Rules

- This is a public GitHub repo. `.gitignore` keeps the Asset Forge app, Kenney's built-in textures, third-party collections and every generated or work folder out of git. Only the user's own packs inside the Asset Forge folder (`Collections/RC_Primitives`, `Textures/32px Microart`, `Textures/128px SurfaceTex`) are committed. Update the `.gitignore` allow-list when the user adds another pack of their own.

- Never modify or delete the user's originals in the Asset Forge folder (Collections, texture packs, Samples). Generated folders can be rebuilt from the scripts.
- A hook blocks permanent deletes. Move unwanted files to `C:\trash\` instead.
- Python is `.venv/Scripts/python` (rebuild with `python -m venv .venv` + `pip install -r requirements.txt`).
- After adding a collection to `Asset Forge 2.5.3 (Windows)/Collections/`, audit its facing (all collections face +z since 2026-10-24, see `recipes.md`). If it faces -z, rotate it with `forge/rotate_collection.py` after showing the user the audit. Then run `forge/extract_library.py --custom-only` and `forge/catalogue.py`. A raw pack that isn't at Asset Forge scale and pivot goes through `forge/import_collection.py` with a config in `forge/packs/` (plan first, user approval, source never modified). Generated collections are rebuilt with `--force`, never hand-edited.
- The user owns the standard (non-Deluxe) edition. Don't use `%` Deluxe blocks, or the `.model` won't fully load in their app.
- Default to broad-strokes quality (mass-producible) unless a work order asks for a hero asset.
